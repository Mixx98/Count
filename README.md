# 🔁 Count – 중복순열 / 조합 출력

재귀 없이 **배열 자리올림 방식**으로 모든 경우의 수를 출력하는 연습 코드입니다.

## 내용

| 클래스 | 설명 | 예시 (`main` 설정) |
| --- | --- | --- |
| `Count_Over` | **중복을 허용**하는 경우 – 각 자리가 0 ~ MAX까지 올라가다 넘치면 다음 자리로 올림 (N진법 카운터) | 0~6 숫자로 4자리 → `[0,0,0,0]` ~ `[6,6,6,6]` |
| `Count_NoOver` | **중복 없이 증가하는** 경우(조합) – 자리올림 후 앞자리보다 큰 값으로 다시 채움 | 1~6 중 5개를 고르는 조합 |

이 코드는 이후 [Hospital](https://github.com/Mixx98/Hospital) 문제에서 병원 조합을 뽑는 데 활용하려고 만들었습니다.

## 실행 방법

```bash
javac Count.java
java Count
```

IntelliJ IDEA 프로젝트(`Count.iml`)로 열어도 됩니다.
